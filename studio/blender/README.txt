THE ANIMATED ZOO - 3D MILO (BLENDER, GPU)

1. Double-click TEST_STILL.bat first. If Blender isn't installed it tells you; RENDER_MILO.bat can install it
   for you (free, via Windows "winget"). The stills appear in the "out" folder in about a minute.
2. Double-click RENDER_MILO.bat to render the full 11-second clip with Milo's voice.
   Output: out\final.mp4. Closing the window is safe: run it again and it continues where it stopped.

Uses your NVIDIA RTX GPU (OptiX). Everything is built by milo_blender.py: no model files to download.
